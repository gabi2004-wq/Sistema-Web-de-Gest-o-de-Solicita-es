# Sistema Web de Gestão de Solicitações

## Introdução
Este projeto consiste em um sistema web desenvolvido para cadastrar, organizar, pesquisar e acompanhar solicitações administrativas.

## Objetivo
Desenvolver uma aplicação simples para facilitar o controle de demandas e melhorar a organização das atividades de uma empresa.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Funcionalidades
- Cadastro de solicitações.
- Definição de prioridade.
- Pesquisa de solicitações.
- Indicadores de acompanhamento.
- Alteração do status para concluída.
- Armazenamento de dados no navegador.

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html no navegador.
